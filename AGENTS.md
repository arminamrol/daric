## Agent skills

### Issue tracker

Local markdown — issues live under `.scratch/<feature>/`. See `docs/agents/issue-tracker.md`.

**Every ticket is implemented on its own branch named after the ticket file** (e.g. `40-plans-entitlements-trial`), branched from `main` and merged by pull request. Never commit ticket work to `main`.

### Domain docs

Single-context — `CONTEXT.md` + `docs/adr/` at repo root. See `docs/agents/domain.md`.
